# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.3.0] - 2025-03-05

### Added

- Partition guidance record: setpbr
- Partition identifier ID: setid
- New partition identifier ID: getid
- Activation partition: setactive
- Partition switching: swap
- NTFS partition display
- MBR write to sysLinux option

### Changed

- Optimize copy speed and increase overall progress display
- Optimize the display of FAT16 and FAT32 partitions
- Modify the default buffer size to 64MB

## [1.2.0] - 2024-12-29
